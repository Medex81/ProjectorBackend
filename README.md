# ProjectorBackend

Микросервисная архитектура бекэнда для многоплатформенных приложений.

## Архитектура

### Микросервисы
1. **Service Registry** (порт 8081) - регистрация и обнаружение сервисов, сбор OpenAPI спецификаций
2. **Identity Provider** (порт 8082) - сервис авторизации и аутентификации
3. **Mail Service** - отправка email уведомлений (через Kafka)
4. **API Gateway** (порт 8080) - единая точка входа, маршрутизация на основе OpenAPI

### Инфраструктура
- **Kafka** - брокер сообщений для межсервисного взаимодействия
- **PostgreSQL** - основная БД (отдельные инстансы под каждый сервис)
- **Redis** - кэширование и временные данные
- **Prometheus + Grafana** - мониторинг и метрики
- **Jaeger** - распределенный трейсинг
